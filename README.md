# WoWCharAuto — автосоздание персонажа для WoW: Forever

Автоматизатор создания персонажа в **World of Warcraft: Forever** (Classic+,
клиент 1.60.1). Приложение с графическим интерфейсом эмулирует клики мыши и
нажатия клавиш в окне игры: выбирает фракцию, расу, пол, класс и внешность,
вводит имя и повторяет попытки создания, пока сервер не примет персонаж.
Предназначен для случаев нестабильного соединения, когда ручное создание
обрывается ошибкой.

> **Дисклеймер.** Использование кликеров может привести к бану. Алгоритм
> создания разработан для минимизации шансов обнаружения. Все риски
> пользователь берёт на себя. Перед каждым запуском приложение показывает
> окно с этим предупреждением.

## Возможности

- **Полный сценарий**: пол → раса → класс → внешность (по слайдерам) →
  имя/фамилия (кириллица или латиница, Unicode-ввод не зависит от раскладки
  клавиатуры) → «Завершить». Для всех параметров внешности задаётся
  абсолютный номер варианта: от 1 до 12 или «Случайно».
- **Проверка доступности имени**: перед «Завершить» бот распознаёт зелёную
  галку или красный крест. При недоступном имени создание останавливается;
  результат проверки записывается в журнал в полном и упрощённом режимах.
- **Цикл повторов**: если создание не удалось (ошибка сети), программа ждёт
  случайный интервал из заданного диапазона и пробует снова.
- **Окно «фракция временно недоступна»**: распознаётся и закрывается кнопкой
  «ОК» автоматически, попытки продолжаются.
- **Периодический релог** (опционально): Esc → экран «Переподключение» →
  Enter → полный сценарий заново, в случайные моменты из диапазона минут.
- **Упрощённый режим** (опционально): без настройки персонажа — только цикл
  «Завершить»/«ОК». Для тех, кто выбрал всё руками.
- **Тестовый режим** (опционально): полный прогон без нажатия «Завершить» —
  вместо этого звуковой сигнал. Для проверки, что всё выбирается верно.
- **Тест релога**: отдельная кнопка запускает настройку персонажа и 3 релога
  с интервалом 30 секунд, повторяя настройку после каждого. «Завершить» не
  нажимается, автоматическая остановка после успеха отключена.
- **Определение успеха**: появление списка персонажей (с автоматической
  остановкой, если включено).
- Журнал действий в окне программы и файле `wow_char_auto_log.txt`,
  отладочные скриншоты в папке `debug_shots` (опционально).

## Требования и подготовка

- Windows, игра в **оконном режиме** (не сворачивать, не перекрывать другими
  окнами во время работы).
- Разрешение окна игры лучше выставить равным выбранному в программе.
- Python не требуется — используйте готовый `WoWCharAuto.exe`.

## Запуск

1. Запустите игру и войдите на экран создания персонажа.
2. Откройте `WoWCharAuto.exe`, примите предупреждение.
3. Заполните настройки (в упрощённом режиме — только интервал попыток).
4. Нажмите «Старт» и не трогайте мышь/клавиатуру.
5. Экстренная остановка: кнопка «Стоп» или бросить курсор мыши в самый
   левый верхний угол экрана.

Настройки сохраняются рядом с exe в `wow_char_auto_settings.json`.

## Сборка из исходников

```
pip install pyautogui pygetwindow pillow pyinstaller
pyinstaller --onefile --windowed --name "WoWCharAuto" wow_char_auto.py
```

Результат — `dist\WoWCharAuto.exe`. Подробности для разработчиков — в
[AGENTS.md](AGENTS.md).

## CI и релизы

GitHub Actions собирает проект на Windows и проверяет запуск `.exe` для каждого
pull request в ветку `release`. После успешной сборки изменений в самой ветке
`release` создаётся GitHub Release с файлом `WoWCharAuto.exe`. Чтобы merge был
доступен только после проверки, в настройках защиты ветки `release` необходимо
требовать pull request и успешный статус `build`.

## Известные ограничения

- Координаты калиброваны под стандартный масштаб UI; при нестандартном
  масштабе в игре отдельные элементы (например, панель классов) могут
  промахиваться — сообщайте о таких случаях через лог и debug-скриншоты.
- Внешность Небеснорождённых: бот работает со вкладкой «лицо» (открыта по
  умолчанию); тату/перья во вкладках «наряд»/«тело» не настраиваются.
- Все данные о расах/классах внешности проверены на живом клиенте
  (съёмка 20 комбинаций: 10 рас × 2 пола).
